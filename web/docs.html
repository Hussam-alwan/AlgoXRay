دليل التشغيل.

Python 3.12 · نموذج محلي للحلول الموثوقة

التشغيل على Windows

.\.venv\Scripts\python.exe -m pip install -e "./backend[dev]"
.\.venv\Scripts\python.exe -m algoxray.cli serve

افتح المتصفح على 127.0.0.1:8000. يمكن استخدام start.bat في المجلد الرئيسي بعد تثبيت الاعتماديات.

تحليل من الطرفية

.\.venv\Scripts\python.exe -m algoxray.cli analyze --problem dijkstra_v1 --fixture dijkstra_premature_visited --seed 2026 --summary

الصق كودك من الموقع

اختر المسألة ثم «كودي الخاص». اكتب دالة solve(payload) أو افتح ملف .py بترميز UTF-8 وحجم أقصى 32 KiB، ثم فعّل تأكيد الكود المحلي واضغط «ابدأ التحليل». لا يلزم تعديل catalog أو كتابة أمر تسجيل.

def solve(payload):
    array = payload["array"]
    target = payload["target"]
    # return a matching index, or -1 if absent
    return -1

الزر «مثال فيه خطأ» يحمّل مثالاً معلناً للتعلم. جرّب Binary Search مع المدخل {"array":[7],"target":7}. الأخطاء النحوية تظهر بسطرها، والاستثناءات مرتبطة بموضعها المسجل. الفحص المنطقي المحدد محدود بأنماط مدعومة وبالتتبع؛ عند نقص الدليل تظهر الحالة الفاشلة مع الامتناع عن تحديد سبب بعينه.

إضافة حل محلي من الطرفية

اكتب دالة solve(payload) في ملف Python، وراجع الملف قبل تنفيذه. يفحص CLI نتيجة الحل وفق العقد، لكن التشخيص الخاص لا يتوفر تلقائياً لكل بنية كود.

.\.venv\Scripts\python.exe -m algoxray.cli analyze --problem dijkstra_v1 --submission reviewed_solution.py --trusted-local-file --summary

التجارب والاختبارات

.\.venv\Scripts\python.exe -m pytest backend/tests -q
.\.venv\Scripts\python.exe benchmarks/run.py --config benchmarks/config.json

واجهات API

GET /api/health · GET /api/session · GET /api/problems · GET /api/fixtures · POST /api/analyze · GET /api/benchmark-summary

مواصفة OpenAPI الفعلية · عقد ملف الأدلة

POST /api/analyze يقبل fixture_id أو source حصرياً. المصدر يتطلب trusted_local_code=true وترويسة X-AlgoXRay-Token بالقيمة التي يرجعها GET /api/session، من الجهاز المحلي فقط؛ الواجهة تدير الرمز تلقائياً. أخطاء المصدر ترجع HTTP 422 مع detail.message وdetail.line عند توفرهما. المسارات المحلية ليست مدخلاً مقبولاً في API.

فحص الشاهد بعد تعديل الحل

اضغط «جرّب تعديلاً على نفس الشاهد»، ثم عدّل الحل وأعد التحليل. يحتفظ المختبر بالمدخل عند تعديل الكود. النتيجة تخص هذا الشاهد فقط. يحتفظ ملف الأدلة بمصدر الحل وبصمته. لإعادته من ملف راجع كوده وشغّل الأمر التالي.

python -m algoxray.cli replay evidence.json --trusted-local-file

قراءة النتيجة

witness_found تعني شاهداً مؤكداً ضمن العقد. inconclusive تعني انتهاء البحث دون شاهد، ولا تثبت صحة الحل. الخطأ في الإجابة والاستثناء والمهلة والخرج المخالف للعقد حالات منفصلة. التلميحات المحددة مرتبطة بمصدر معلوم وأحداث مسجلة؛ يصرح النظام بالامتناع عندما لا يكفي الدليل.

حد التشغيل

هذا نموذج محلي. لا تفتح المنفذ للإنترنت ولا تستخدمه لتشغيل كود مجهول. العملية المستقلة والمهلات لا تشكل عزلاً أمنياً كاملاً.
