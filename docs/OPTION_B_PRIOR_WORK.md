## Closest repair and educational systems — identified sources
- Tillmann et al., Code Hunt: Searching for Secret Code for Fun (2014), https://www.microsoft.com/en-us/research/publication/code-hunt-searching-for-secret-code-for-fun/ . Pex-generated test cases serve as clues against secret code; counterexample feedback is not new. Compare the explicit replay/trace evidence and staged observations.
- Rivers and Koedinger, Data-Driven Hint Generation in Vast Solution Spaces: A Self-Improving Python Programming Tutor (2017), https://www.krivers.net/research.html . ITAP traverses solution spaces to produce next-step hints. This is a different feedback mechanism; absence of particular evidence-verification features is not established.
- Liffiton et al., CodeHelp (2023), https://arxiv.org/abs/2308.06921 . Guardrails aim to provide assistance without directly revealing solutions; authors report a course deployment. AlgoX-Ray has no learner study.
- Orvalho et al., Counterexample Guided Program Repair Using Zero-Shot Learning and MaxSAT-based Fault Localization (AAAI 2025), https://doi.org/10.1609/AAAI.V39I1.32046 . The work combines MaxSAT fault localization and counterexample-guided LLM repair; its reported evaluation covers 1,431 faulty student C programs. Counterexamples plus localization are established prior art, not a novelty claim.
- Orvalho, Janota and Manquinho, MENTOR (JSS 2026), https://doi.org/10.1016/j.jss.2025.112690 . Combines formula-based localization, variable mapping and iterative repair validated on tests. It can return repaired code or highlight faulty statements. Its repair success rates cannot be compared with AlgoX-Ray's witness-discovery rates.
- MacIver and Donaldson, ECOOP 2020, https://doi.org/10.4230/LIPIcs.ECOOP.2020.13 . Internal reduction works by regenerating from smaller random-choice sequences, reducing validity problems; AlgoX-Ray reuses this mechanism.

Sources are publisher/author abstracts and descriptions. Full-paper review and a direct comparative experiment remain open. The testable claim is whether a narrow rule verifier with explicit abstention improves factual support on the same witness without unacceptable loss of coverage, not whether this project invented counterexamples or beats repair systems. No priority claim established.


## Detailed targeted full-text comparison
AAAI 2025, Orvalho et al., https://arxiv.org/html/2502.07786v1 , sections 4–5: the repair loop starts from a faulty C submission, assignment specification, reference and existing I/O tests. MaxSAT identifies candidate statements, an LLM fills missing parts, and an unsuccessful repair is fed an I/O test it fails. The evaluation uses 1,431 defective C submissions. The outcome is repair quality/extent rather than learner-facing trace claim support.
MENTOR, Orvalho et al., https://doi.org/10.1016/j.jss.2025.112690 , author manuscript sections 3–4 and 6: combines clustering, variable alignment, formula-based localization and iterative LLM repair; tests repairs on the C-Pack corpus of 1,431 faulty submissions over 25 exercises. It can show faulty statements or code, and proposes more detailed hints and a future user study. The reported repair rates are not comparable to AlgoX-Ray's witness discovery.
A narrower hypothesis for AlgoX-Ray is that deterministic, verifiable observations tied to a legal replayed witness permit useful staged debugging feedback without returning a repair. Evaluate this as factuality and coverage, not as a claimed absence of similar mechanisms in all earlier tools.
