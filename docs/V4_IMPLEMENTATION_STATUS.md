## How to run on this PC
Keep Docker Desktop running. V4 is live on 8002; stop/restart only V4, not V3. Install Ollama from https://ollama.com/download/windows, then `ollama pull qwen2.5-coder:7b` and `ollama run qwen2.5-coder:7b`. At the checkpoint, localhost:11434/api/tags was unreachable, so real AI contract draft, explanation, and repair were not tested. No cloud credentials used. Check model health in V4 before enabling local AI. Use correct/mutant examples, review and approve package explicitly, then analyze. For a new problem, paste a manifest or ask model for a draft when available; supply reviewed reference and at least two independently known outputs. Don't approve unchecked generated code. 
For fresh local setup build the dedicated worker with `python tools/prepare_v4_worker.py`; it writes local runtime image ID. Keep all V4 evidence/package files local and ignored by git. Run the app via `python -m uvicorn algoxray.api:app --host 127.0.0.1 --port 8002`. 
Docker boundaries reduce risk, not a security guarantee. Guest-generated trace is not authenticated against hostile source. Public service is disabled; the existing V3 trusted-code path is not sandboxed. Finite controls establish agreement only on named cases. V4 is not yet evidence for manuscript claims about arbitrary problems or AI accuracy.
