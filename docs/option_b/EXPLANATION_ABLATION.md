# Matched witness explanation ablation
Use the same implemented deterministic hint generator and the same full-variant witnesses with (A) source only, (B) source and checked witness, (C) source, witness and trace. For A, execution evidence is absent and this conservative explainer is designed to abstain. This is an information-availability ablation, not a comparison with a capable general-purpose language model. Report candidate/published counts and specific coverage. Apply the verifier to each candidate before publication. A natural set with zero rejected candidates cannot establish improved factuality. Report separate deliberately corrupted-prose and missing-event negative controls, never combine them with natural claims.
The script checks measured source hashes and validates full bundles. It produces a deduplicated, shuffled human review packet (source, witness, trace, proposed statement, cited events) and a separate mapping key. The key must be hidden from reviewers until independent ratings lock; even then some contexts may be inferable. No human review has been performed by this script.
Run after v2 evaluation: python tools/evaluate_option_b_explanations.py --input results/option-b-v2 --out results/option-b-v2/explanation-review
