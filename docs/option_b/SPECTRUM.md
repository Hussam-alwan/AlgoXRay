# Experimental spectrum localization
Option B.2 can collect up to four additional complete, concordant traces on distinct legal cases. It compares line presence in sampled passing/failing executions using Ochiai. Each rank links to a failing-witness event. This is a small, potentially biased sample, not causal localization or a calibrated probability. No rank if either outcome class is absent. A separate narrow Max Subarray observation validates return of zero on an all-negative legal input; it does not prove the initialization caused the defect. Dynamic data dependence is not implemented.
