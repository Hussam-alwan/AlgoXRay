# V3 development — not held-out evaluation
New rules are developed from the original 30-file V1/V2 development corpus. A positive-weight shortest path must be a simple path; an unattainable finite returned cost is an independently checkable symptom. The second rule recognizes only a direct maximum-element or prefix-only return (or one verified array alias), checks the returned restricted optimum and gives a legal better segment. These are narrow evidence-backed observations, not causal localization accuracy. V2 claim reconstruction remains gated by evidence revision option-b.2; new bundles use option-b.3. Do not rerun the external pilot and call it blind or independent after inspecting it. Preserve old measurements.
