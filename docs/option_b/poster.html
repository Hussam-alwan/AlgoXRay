AlgoX-Ray

Counterexample-driven visual debugging and evidence-grounded hints

ICIPS 2026 · Option B research prototype · author review required

Measured Option B v1 (3362119) — technical evaluation; v2 results pending. Author review required.

Research problem

A wrong answer identifies failure, not its cause. How can an educational debugging tool connect feedback to a reproducible input and recorded evidence?

Proposed contribution

One inspectable evidence bundle connects legal witness, reference output, source hash, replay, frame/event IDs and checked observations. Abstain when specific evidence is insufficient.

Pipeline

Legal generation →Oracle check →Replay →Reduction →Trace →Verified hints

Three bounded problems

Dijkstra: two distance oracles.

Binary search: any valid matching index.

Maximum subarray: exhaustive segments and Kadane.

Designed example

[-5, -2, -7]
expected: -2
empty-segment bug: 0

Analytically derived example; not a new recorded run.

Measured v1 evaluation

30 program files · 5 seeds · 3 variants · 450 runs. 225/225 faulty runs found witnesses; 0/225 control accusations. 675/675 recorded replays matched; 210 certificates audited. Full variant: 59/75 strictly reduced; 20/75 received a specific observation. Human review pending.

Historical evidence only

Previous core release: 240/240 faulty trials detected, 0/240 control accusations, 72/72 replay attempts matched, 6/24 audit witnesses received a specific observation.

Different frozen source; not Option B performance or a learner study.

Limitations

No general root-cause claim, no proof of correctness from an inconclusive search, no hostile-code sandbox, no measured learning benefit.
