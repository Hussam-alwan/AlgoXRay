# V2 regression protocol
This revision follows inspection of v1 and therefore is not a fresh held-out evaluation. Preserve v1 raw results and source freeze. V2 uses the same 30 files, 5 seeds, and 3 arms; the full arm adds a bounded diagnostic sampling budget (3 additional complete traces, up to 12 candidate inputs). Discovery and reduction budgets stay unchanged. Default persistent-worker mode is used for comparison; fresh-process mode is verified separately, not assumed equivalent for timing. Record source commit, test/fixture/source/UI hashes, lockfile, corpus hashes and environment before execution. Store new results under results/option-b-v2.
