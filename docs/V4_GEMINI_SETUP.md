# Gemini integration — local V4
Select Qwen local (default), Gemini 4 Hydrogen, or Gemini 3.8 Flash from /v4. Select the cloud consent checkbox before any Gemini request. Gemini receives only the required task data, which can include problem statements, source, counterexamples and trace; do not send confidential code. Use Windows user environment variable GEMINI_API_KEY (server reads it directly if missing from process environment). No key is exposed to the browser, stored in Git, or sent to the container. No automatic cloud fallback.

Requests are JSON-schema constrained, and model output is independently checked by the existing manifest/observation validators. A valid draft is not an approved problem; model hypotheses are not verified root causes. Generated patches still require owner review. Fixed API endpoint and model allowlist, 90-second network timeout; no automatic retry. Local SQLite ledger reserves each attempted call and caps each model at 5 attempts per rolling minute and 20 per rolling 24h, including failures. This is not Google account-wide quota or a guarantee of zero charges; no billing enabled by this integration. External usage and earlier manual smoke calls are not counted. Cancellation of a cloud inference already submitted cannot be guaranteed.
